# Roza's World 🌈

A colorful offline Android mini-adventure starring Roza. The first build includes a scene map, coins and stars, outfit changes, a pet companion, family-approved daily missions, and local progress saves.

## Build APK with GitHub Actions

A push to `main` triggers the workflow. You can also open **Actions → Build Roza's World APK → Run workflow**.

Download the artifact named `rozas-world-debug-apk` from a successful workflow run. It contains `app-debug.apk` for installing on an Android device for testing.

## Current status

This is a playable starter version, not yet a finished store release. Mini-games currently use simple interactions and reward logic; they are scaffolding for richer gameplay. Test the app on a real device and check Persian text/emoji rendering before wider use.

## Privacy

The app requests no internet, SMS, location, contacts, or microphone permissions. Game progress is stored locally on the device.
