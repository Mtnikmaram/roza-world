# Roza's World 🌈

A colorful, kid-friendly Android adventure game starring Roza.

## Planned features

- A colorful world map with home, forest, village, beach, castle, and snow areas
- Character customization and room decoration
- A magical pet companion
- Coins, XP, levels, daily missions, and achievements
- Mini-games: memory cards, puzzles, collecting stars, and obstacle runs
- Optional Parent Mode for family-approved real-world tasks and rewards
- Local saves; no account or sensitive Android permissions required

## Build APK

The Android project is built by GitHub Actions. Open **Actions** and select the Android APK workflow. When the workflow succeeds, download the APK from the run's **Artifacts** section.

This is a family-friendly project. The initial build is intended for local installation/testing; a release suitable for public distribution still needs device testing and store-policy review.
